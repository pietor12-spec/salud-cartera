# Salud de mi cartera

App web con la salud de mis acciones: dividenderas, growth, ventas y watchlist.

- **Úsala desde el navegador**: https://pietor12-spec.github.io/salud-cartera/
- **Instálala como app**: pestaña *Datos* → *Instalar app* (o menú del navegador → *Añadir a pantalla de inicio*).
- **Tus datos no están en este repositorio.** Se guardan solo en el navegador de cada dispositivo.
- Para cargarlos: pestaña *Datos* → *Importar JSON* con el archivo `salud-cartera-AAAA-MM-DD.json`.
- La app funciona sin conexión.
